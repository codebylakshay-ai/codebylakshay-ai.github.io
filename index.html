AI Agents

I also build the systems that use these models

Beyond training data, I design and build AI agents: LLM-driven workflows that plan, call tools and check their own output. Knowing how models are trained helps me see where agents will fail, and building agents shows me what good training data needs to cover. On Outlier's Terminal-Bench project I wrote the tasks that test agents like these.

  • Tool calling & function designDefining tools, schemas and the instructions that make agents use them correctly.
  • Multi-step workflowsAgents that break a task into steps, act, and verify results before moving on.
  • Retrieval (RAG)Grounding answers in documents so outputs stay factual.
  • EvaluationTest sets and rubrics to measure agent quality, using the same skills I use in AI training.
Typical agent loop
01receive task // user goal + context
02plan steps // decompose the goal
03call tools // search, APIs, code, files
04check output // against a rubric
05retry or return // with sources
